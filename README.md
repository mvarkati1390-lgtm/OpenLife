# OpenLife

بازی جهان‌باز آنلاین اندروید با دوربین سوم‌شخص و رابط فارسی.

## بخش‌های پروژه
- `unity/` — کد کلاینت Unity، کنترل سوم‌شخص، محیط آزمایشی، رابط ورود و همگام‌سازی موقعیت بازیکنان
- `server/` — API حساب‌ها، پروفایل، موقعیت بازیکنان، گزارش‌ها و مجوزهای مدیریتی
- `admin-panel/` — پنل مدیریت فارسی
- `docs/` — راهنماها و نقشه راه
- `render.yaml` — الگوی استقرار سرور روی Render

## وضعیت واقعی توسعه
- نمونه اولیه Unity و کنترل لمسی: کدنویسی شده، هنوز در Unity Editor یا گوشی آزمایش نشده
- ثبت‌نام و ورود: API و UI اولیه اضافه شده
- دنیای مشترک: ذخیره و دریافت موقعیت با HTTP دوره‌ای؛ هنوز چندنفره سریع و نهایی نیست
- پنل مدیریت: رابط و API نقش‌ها، اخطار، مسدودسازی، گزارش و رویدادها اضافه شده
- سرور: کد و پیکربندی استقرار آماده‌اند، اما هنوز روی اینترنت Deploy نشده‌اند
- APK: هنوز ساخته نشده است
