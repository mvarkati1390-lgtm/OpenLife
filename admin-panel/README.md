# پنل مدیریت OpenLife

پنل مدیریت فارسی بازی در این پوشه قرار دارد.

## امکانات پیاده‌سازی‌شده
- ورود مدیران
- آمار کل بازیکنان، آنلاین‌ها، مسدودها و گزارش‌های باز
- جست‌وجوی بازیکنان
- اخطار، مسدودسازی و رفع مسدودسازی
- تعیین نقش توسط مالک
- مشاهده گزارش‌های بازیکنان
- مشاهده رویدادهای مدیریتی برای مالک و مدیر

## انتشار روی GitHub Pages
1. در مخزن GitHub به Settings → Pages بروید.
2. در بخش Build and deployment، گزینه Source را روی GitHub Actions قرار دهید.
3. workflow با نام Deploy OpenLife admin panel پس از تغییرات پوشه `admin-panel/` اجرا می‌شود.
4. پس از موفقیت، نشانی Pages در خروجی workflow نمایش داده می‌شود.
5. در صفحه ورود پنل، آدرس HTTPS سرور واقعی OpenLife را وارد کنید.

## امنیت
پنل رمز یا توکن مدیریتی ثابتی در کد ندارد. توکن ورود فقط در حافظه همان صفحه نگهداری می‌شود و با تازه‌سازی صفحه از بین می‌رود. دسترسی واقعی را سرور با JWT و نقش کاربر بررسی می‌کند. پس از انتشار، دامنه پنل را در مقدار `CORS_ORIGIN` سرور مشخص کنید.
