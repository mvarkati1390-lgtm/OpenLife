# پنل مدیریت OpenLife

پنل وب فارسی برای مدیریت بازی.

## امکانات برنامه‌ریزی‌شده
- ورود امن مدیران
- نمایش تعداد بازیکنان آنلاین
- جست‌وجوی بازیکن و مشاهده پروفایل
- اخطار، مسدودسازی و رفع مسدودسازی
- مشاهده گزارش‌ها و رویدادها
- ارسال پیام سراسری
- مدیریت نقش‌ها و مشاهده سابقه اقدامات

## سلسله‌مراتب نقش‌ها
- مالک: تنها نقشی که می‌تواند مدیران و ادمین‌ها را منصوب یا عزل کند.
- مدیر و ادمین: دسترسی محدود بر اساس مجوزهای سرور.
- ناظر: بررسی گزارش‌ها با دسترسی محدود.
- بازیکن: بدون دسترسی مدیریتی.

## امنیت
این پنل نباید صرفاً با مخفی‌کردن دکمه‌ها امنیت ایجاد کند؛ تمام مجوزها باید در سرور کنترل شوند. اطلاعات ورود و کلیدهای محرمانه نباید در کد سمت مرورگر قرار بگیرند.
