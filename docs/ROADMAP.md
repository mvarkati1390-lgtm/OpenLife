# نقشه راه OpenLife

## هدف
ساخت بازی آنلاین جهان‌باز برای اندروید با دوربین سوم‌شخص، رابط فارسی و سرور مرکزی.

## مرحله ۱ — پایه پروژه
- [x] ساخت مخزن و معرفی پروژه
- [ ] تعیین نسخه Unity و ساخت پروژه اصلی
- [ ] حرکت شخصیت سوم‌شخص و دوربین دنبال‌کننده
- [ ] محیط آزمایشی قابل گشت‌وگذار
- [ ] رابط کاربری فارسی و راست‌به‌چپ

## مرحله ۲ — آنلاین
- [ ] ثبت‌نام و ورود امن
- [ ] ساخت شخصیت و ذخیره اطلاعات بازیکن
- [ ] همگام‌سازی بازیکنان در یک محیط آزمایشی
- [ ] چت و وضعیت آنلاین

## مرحله ۳ — مدیریت
- [ ] پنل مدیریت فارسی
- [ ] نقش‌ها و مجوزها در سمت سرور
- [ ] گزارش اقدامات مدیران
- [ ] ابزار اخطار، مسدودسازی و رفع مسدودسازی

## اصول امنیتی
- هیچ رمز، کلید خصوصی یا توکن مدیریتی داخل بازی اندروید قرار نگیرد.
- مجوزها در سرور بررسی شوند، نه فقط در رابط کاربری.
- همه اقدامات مدیریتی ثبت و قابل پیگیری باشند.
- فقط مالک بازی بتواند مدیر یا ادمین منصوب یا عزل کند.
