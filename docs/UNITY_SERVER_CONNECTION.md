# اتصال کلاینت Unity به API

فایل `OpenLifeApiClient.cs` ارتباط HTTP پایه را فراهم می‌کند:
- ورود و ثبت‌نام
- نگهداری توکن نشست
- دریافت پروفایل
- ارسال گزارش بازیکن
- timeout و مدیریت خطا

## تنظیم نشانی سرور
در شروع بازی، از نمونه `OpenLifeApiClient.Instance` متد `ConfigureServer("https://your-domain")` را صدا بزنید. برای آزمایش روی کامپیوتر، `127.0.0.1` فقط همان کامپیوتر است؛ روی گوشی باید IP شبکه محلی یا دامنه سرور وارد شود.

## نکته مهم
این نسخه ارتباط REST را وصل می‌کند، نه Socket.IO چندنفره را. حرکت بازیکنان هنوز به لایه realtime کلاینت نیاز دارد. توکن در PlayerPrefs ذخیره می‌شود؛ برای انتشار باید ذخیره امن‌تر و چرخه تمدید/ابطال نشست اضافه شود. از HTTP ساده فقط در شبکه آزمایشی استفاده کنید و برای اینترنت HTTPS لازم است.
