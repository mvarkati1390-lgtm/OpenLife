# راه‌اندازی سرور OpenLife
1. Node.js نسخه 20 یا بالاتر نصب کنید.
2. در پوشه server دستور npm install را اجرا کنید.
3. فایل .env.example را به .env کپی و مقادیر محرمانه را تغییر دهید. رمز مالک و JWT_SECRET را در مخزن عمومی قرار ندهید.
4. دستور npm start را اجرا کنید.
5. نشانی سرور را در پنل admin-panel/index.html وارد کنید.

این نسخه نمونه اولیه است؛ پیش از انتشار عمومی باید HTTPS، محدودسازی نرخ درخواست، اعتبارسنجی سخت‌گیرانه، مدیریت نشست و آزمون امنیتی اضافه شود. ارتباط لحظه‌ای پایه و وضعیت آنلاین پیاده شده‌اند؛ همگام‌سازی کامل جهان و ذخیره موقعیت‌ها هنوز نیاز به توسعه دارد.
