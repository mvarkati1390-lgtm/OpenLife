# سرور OpenLife

این بخش مسئول حساب‌های بازیکنان، ذخیره‌سازی، وضعیت آنلاین و مجوزهای مدیریتی است.

## مسئولیت‌ها
- احراز هویت و نشست‌های بازیکن
- پروفایل و اطلاعات ذخیره‌شده
- وضعیت آنلاین و ارتباط چندنفره
- نقش‌ها و مجوزهای مدیریتی
- ثبت رویدادهای امنیتی و مدیریتی

## قواعد دسترسی
- نقش‌ها فقط در پایگاه داده و سمت سرور معتبر هستند.
- کلاینت نمی‌تواند نقش خودش را تعیین یا ارتقا دهد.
- فقط مالک می‌تواند مدیر یا ادمین منصوب یا عزل کند.
- عملیات حساس باید همراه شناسه اجراکننده، زمان و نتیجه ثبت شوند.

## وضعیت
پیاده‌سازی سرور هنوز انجام نشده است. پیش از انتشار عمومی باید احراز هویت، اعتبارسنجی ورودی‌ها، محدودسازی درخواست‌ها و پشتیبان‌گیری اضافه شوند.
