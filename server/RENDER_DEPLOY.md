# استقرار سرور روی Render

این مخزن فایل `render.yaml` دارد تا سرویس وب Docker و دیسک پایدار SQLite را تعریف کند.

1. در Render از گزینه New Blueprint استفاده کنید و این مخزن GitHub را انتخاب کنید.
2. تنظیمات `render.yaml` را بازبینی و سرویس را ایجاد کنید. این پیکربندی از پلن پولی Starter و دیسک پایدار استفاده می‌کند؛ هزینه و دسترس‌پذیری را در Render بررسی کنید.
3. بعد از Deploy، نشانی HTTPS سرویس را از داشبورد Render بردارید و در تنظیمات سرور بازی وارد کنید.
4. مقدار رمز اولیه مالک به صورت secret در تنظیمات سرویس تولید می‌شود؛ آن را فقط از داشبورد امن سرویس ببینید و در چت یا مخزن عمومی منتشر نکنید.
5. برای پنل مدیریت، مقدار `CORS_ORIGIN` را از `*` به دامنه دقیق پنل تغییر دهید.

## مهم
- این فایل‌ها فقط زیرساخت استقرار را آماده می‌کنند؛ خود سرویس تا زمانی که شما در Render آن را ایجاد نکنید اجرا نمی‌شود.
- قبل از انتشار عمومی، HTTPS، پشتیبان‌گیری پایگاه داده، آزمون بار و بازبینی امنیتی لازم است.
- کلاینت Unity فعلاً همگام‌سازی سبک موقعیت را با درخواست‌های دوره‌ای HTTP انجام می‌دهد؛ Socket.IO سرور برای کلاینت Unity هنوز وصل نشده است.
