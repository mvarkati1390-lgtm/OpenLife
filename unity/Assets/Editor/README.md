# آماده‌سازی پروژه در Unity

1. پوشه `unity` را با Unity 2022.3 LTS باز کن.
2. صبر کن تا Unity همه فایل‌ها را Import کند.
3. از منوی بالای Unity گزینه `OpenLife > Setup Prototype Scene` را انتخاب کن.
4. صحنه `Assets/Scenes/OpenLife.unity` ساخته و به Build Settings اضافه می‌شود.
5. دکمه Play را بزن تا نمونه شهر، شخصیت و کنترل‌ها ساخته شوند.

برای ساخت APK:
1. از Unity Hub ماژول Android Build Support به‌همراه Android SDK & NDK Tools و OpenJDK را نصب کن.
2. در Unity از File > Build Settings پلتفرم Android را انتخاب و Switch Platform کن.
3. مطمئن شو صحنه OpenLife در Scenes In Build فعال است.
4. Build را بزن.

این دستورالعمل ساخت را آماده می‌کند؛ ساخت و آزمایش واقعی APK باید در Unity Editor روی رایانه انجام شود.
