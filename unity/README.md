# کلاینت Unity

این پوشه برای پروژه Unity اندروید OpenLife است.

## تنظیمات هدف
- پلتفرم: Android
- دوربین: سوم‌شخص
- رابط: فارسی و راست‌به‌چپ
- سبک بصری: واقع‌گرایانه، با اولویت عملکرد مناسب موبایل

## اولین نمونه قابل بازی
1. ساخت صحنه آزمایشی کوچک
2. افزودن کنترلر شخصیت سوم‌شخص
3. افزودن دوربین دنبال‌کننده
4. افزودن کنترل لمسی حرکت و چرخش
5. افزودن منوی فارسی

## نکته
فایل‌های پروژه Unity باید با نسخه مشخص Unity ساخته و از طریق Unity Editor بررسی شوند. این پوشه فعلاً مستندات شروع کار است و هنوز پروژه قابل نصب APK نیست.
