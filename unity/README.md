# کلاینت Unity

کد اولیه کلاینت OpenLife برای Android و Unity 2022.3.62f1.

## کدهای موجود
- کنترل حرکت سوم‌شخص با CharacterController
- دوربین دنبال‌کننده
- کنترل لمسی مجازی
- ساخت محیط و شخصیت آزمایشی
- صفحه ورود/ثبت‌نام و تنظیم آدرس سرور
- ارسال موقعیت بازیکن و دریافت بازیکنان دیگر از API

## تنظیمات
- هدف عملکرد اولیه: 30 FPS
- دوربین: سوم‌شخص
- پلتفرم هدف: Android
- رابط: فارسی (فونت و شکل‌دهی فارسی نیازمند بررسی در Unity است)

## راه‌اندازی سرور
راهنمای [README_SERVER_SETUP.md](README_SERVER_SETUP.md) را دنبال کنید و دامنه HTTPS واقعی سرور را در صفحه ورود وارد کنید.

## محدودیت‌ها
این پروژه هنوز در Unity Editor باز و کامپایل نشده و APK آماده نصب ندارد. کد همگام‌سازی فعلی از HTTP polling استفاده می‌کند و کلاینت Socket.IO هنوز پیاده‌سازی نشده است. ظاهر فعلی نمونه اولیه با شکل‌های ساده است، نه گرافیک واقع‌گرایانه نهایی.
