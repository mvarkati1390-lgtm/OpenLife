# تنظیم سرور داخل بازی

در صفحه ورود OpenLife، کادر «آدرس سرور HTTPS» را پر کنید و «ذخیره آدرس سرور» را بزنید.

نمونه نشانی پس از استقرار:
`https://YOUR-SERVICE.onrender.com`

این فقط نمونه است؛ باید دامنه واقعی سرویس مستقرشده را جایگزین کنید. از `127.0.0.1` در گوشی استفاده نکنید؛ آن نشانی به خود گوشی اشاره می‌کند، نه سرور اینترنتی.

پس از ذخیره نشانی، ثبت‌نام یا ورود را انجام دهید. همگام‌سازی موقعیت بازیکنان فقط برای حساب واردشده فعال است. نسخه فعلی موقعیت‌ها را با درخواست‌های HTTP دوره‌ای می‌فرستد و بازیکنان دیگر را با فاصله زمانی کوتاه دریافت می‌کند؛ این روش نمونه اولیه است، نه زیرساخت مقیاس‌پذیر برای تعداد زیاد بازیکن.
